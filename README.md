# natyv-io/core

The natyv-core runtime -- the app that gets bundled/shipped, and what a natyv guest app actually
runs on. See the [natyv-io org page](https://github.com/natyv-io) for the project overview, install
instructions, and roadmap, and this repo's own `CLAUDE.md` for architectural reference.

Depends on [natyv-io/shared](https://github.com/natyv-io/shared) for the `conf.natyv.json`
schema/parser, shared with [natyv-io/cli](https://github.com/natyv-io/cli).
